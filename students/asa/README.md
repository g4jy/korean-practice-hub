# Asa Korean practice

Animals, actions and little sentences + Greetings and short introductions

Independent local progress and backups. New course material is teacher-authored practice guided by reviewed topics, not a claim that every word was already taught. Audio coverage is validated in audio-manifest.json. No private transcript, calendar event, student-platform ID or personal contact details are published.

Open index.html after extracting the full package; retain ../shared/audio. For microphone and installed offline app features use the HTTPS URL.
